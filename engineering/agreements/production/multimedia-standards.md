# Working Agreement: Multimedia Standards

**Scope:** Production unit
**Date:** 2026-03-08

---

## Purpose

Define quality and format standards for multimedia content (photography, graphics, video, interactive).

## Standards

### Photography

| Use | Format | Min Resolution | Notes |
|---|---|---|---|
| Hero / cover | WebP + AVIF fallback | 2400px wide | Astro handles conversion |
| Article inline | WebP + AVIF fallback | 1200px wide | Responsive srcset |
| Thumbnail | WebP | 600px wide | Generated from source |
| Source archive | Original (RAW/TIFF/PNG) | Native | Stored outside site repo |

### Graphics and Diagrams

- Vector formats (SVG) preferred for diagrams, charts, illustrations
- Raster formats for photographs and complex visuals
- Consistent with Yo-Yodyne brand palette and typography

### Video (Future)

- Standards to be defined when video content is produced
- Placeholder: web-optimized MP4 (H.264), with poster frames

### Interactive (Future)

- Built as Astro islands with selective hydration
- Standards to be defined per project

### File Organization

- Source media stored in `production/assets/` (originals, working files)
- Web-ready media co-located with content in `site/src/content/` collections
- Astro's image optimization handles format conversion and responsive variants

### Attribution

All media MUST be attributed. For PI's own photography, credit as "Neilson P. Eney / Yo-Yodyne."

## Exceptions

- Placeholder images during development need not meet resolution standards
- Diagrams generated by tools (mermaid, etc.) are exempt from manual quality review

## Review

Reviewed when new media types are introduced.
