# Changelog

All notable changes to Yo-Yodyne are documented here.

## [Unreleased]

### Added
- Vinyl library organization system — research article, openspec specs, and design docs
- Dynamic research article routing (`/research/[slug]`)

## [0.1.0-alpha.1] — 2026-03-12

### Added
- OpenSpec project structure with OPSX workflow (propose → fast-forward → apply → archive)
- Organizational design: Research, Engineering, Production, Tech units
- Working agreements: common (creative autonomy, commit conventions, artifact metadata, review process, dependency management) and unit-specific
- Agent team definitions: PI, Researcher, Engineer, Technician, Writer, Creative Director
- Astro site scaffold with Content Collections (research, experiments, projects)
- Wabi-sabi design system: Cormorant Garamond + Karla typography, off-white palette, gold accent
- Self-hosted variable fonts
- Cloudflare Pages deployment at labs.yo-yodyne.com
- CI/CD: site deployment, release gating, spec lint workflows
- Dependency registry and architecture decision records
- Creative autonomy principle as core working agreement
- Creative brief template for cross-unit Production work
