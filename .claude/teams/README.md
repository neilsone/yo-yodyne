# Agent Teams

This directory defines roles for AI agents that assist with research, engineering, and creative work across the Yo-Yodyne project.

Each file describes an agent's unit assignment, responsibilities, working agreements, and behavioral constraints. The agents operate within the [OPSX workflow](../../openspec/project.md) and are bound by the same specs and working agreements as any contributor.

This is an experiment in structured agent orchestration — treating AI assistants as team members with documented roles rather than ad hoc tools.

## Roles

| Agent | Unit | Summary |
|---|---|---|
| `pi.md` | All (cross-unit) | Principal Investigator — strategic oversight, approvals, brand |
| `researcher.md` | Research | Literature review, experiment design, paper writing |
| `engineer.md` | Engineering | Implementation, site, CI/CD, release management |
| `writer.md` | Production | Content writing, editing, brand voice |
| `creative-director.md` | Production | Creative concepts, multimedia, briefs |
| `technician.md` | Tech | Standards, architecture, dependency management |
